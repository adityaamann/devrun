// how it works

01

You give it a GitHub URL

Point devrun at any public GitHub repository. It doesn't matter what stack it is — Node.js, Python, anything.

devrun https://github.com/someone/anyrepo
02

AI reads the repo and figures it out

devrun clones the repo, reads all config files — package.json, requirements.txt, Dockerfile, .env.example — and sends them to an AI model. The AI identifies the project type, the exact install command, the start command, and any environment variables needed.

03

It sets everything up for you

devrun runs the install command automatically, creates a .env file if environment variables are needed, and tells you exactly how to start the project. No guessing, no reading broken READMEs.

04

Stay up to date with one command

When devrun releases updates, you don't need to manually reinstall anything. One command pulls the latest version and reinstalls automatically.

devrun --update

// get started

1

Clone devrun

git clone https://github.com/adityaamann/devrun && cd devrun
2

Install dependencies

pip3 install -r requirements.txt
3

Get a free Groq API key — no credit card needed

console.groq.com → sign up → create API key

Takes 2 minutes. Free tier is more than enough.

4

Create a .env file in the devrun folder

# .env
GROQ_API_KEY=your_key_here
5

Install devrun as a CLI command

pip3 install -e .
6

Use it on any repo

devrun https://github.com/anyone/anyrepo
7

Keep devrun up to date

devrun --update

Pulls latest changes from GitHub and reinstalls automatically.
